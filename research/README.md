# SimGenr Research

本目录保存与多模态电网潮流计算项目直接相关的研究说明和调研材料。实现代码、配置和测试仍位于仓库原有目录中，生成数据、运行输出、检查点和文档生成缓存不进入版本库。

## 核心目标

构建一个可控、可解释、可复核的多模态电网潮流 Benchmark。场景由地形、水文、天气、城市活动、源荷设施、电网拓扑和运行状态共同构成，节点与线路潮流标签逐步由成熟 AC 潮流求解器产生。

总体路线为：

1. 使用公开数据确定变量范围、相关关系和典型统计规律。
2. 使用物理方程、空间统计、图算法和优化模型生成可控场景。
3. 使用 AC/DC 潮流求解器产生可核验的节点与线路标签。
4. 构建 IID、OOD、模态缺失、拓扑扰动和安全场景的统一评测协议。

## 目录内容

- `docs/多模态电网潮流计算_项目描述与调研框架.docx`：当前系统内容、核心目标、公开数据现状、期望能力和研究边界。
- `docs/多模态电网潮流计算_分阶段调研计划.docx`：按照世界生成和电网运行阶段组织的调研问题。
- `slides/多模态电网潮流计算_项目描述与目标.pptx`：用于介绍项目现状和研究方向的汇报稿。

## 代码对应关系

- `world_generator/terrain`、`hydrology`、`land`：地形、水文和静态土地约束。
- `world_generator/climate`、`weather`：基础气候与小时天气。
- `world_generator/city`、`land_use`、`energy`：城市、土地利用、源荷设施与资源条件。
- `world_generator/grid`：母线候选、拓扑、电气参数和线路走廊。
- `world_generator/operation`：潮流、网络更新、储能规划和调度。
- `world_generator/dataset`、`datasets/*.md`：多模态样本封装、字段说明和加载方式。
- `models`、`configs/models`、`scripts/train_physics_gst.py`：预测基线、图时空模型和训练入口。

## 版本协作约定

- 研究结论发生变化时，同步更新本目录中的说明材料及对应实现。
- 大规模生成样本、`outputs/`、`checkpoints/` 和文档预览缓存保持本地，不直接提交 Git。
- 代码变更尽量附带对应配置、测试或可复现命令。
- 新的解析规律先记录数据来源、变量单位、假设和验证指标，再进入生成器默认流程。

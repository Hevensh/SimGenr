# 地理、土地、城市与能源候选阶段的研究及修正

检索日期：2026-09-09。下面区分文献中的方法、代码中的近似和需要标定的参数。代码的目标是具有守恒关系和明确单位的合成世界；没有把未经观测验证的打分公式标记为真实预测模型。

## 1. 地形与地形导数

**文献。** [Perlin (2002), Improving Noise，作者参考实现](https://cs.nyu.edu/~perlin/noise/)给出梯度噪声和连续插值；[作者论文](https://mrl.cs.nyu.edu/~perlin/paper445.pdf)讨论二阶连续性。

**原问题。** legacy 每幅图按自身极值重新缩放，邻接窗口会出现不同地形；`roughness` 又按全图最大局部起伏归一化，远处一个高山会改变既有平原的粗糙度。原 fBm 截止尺度允许略低于两倍网格宽的波长。

**处理。** 默认使用已有 `multiscale_v2` 的世界坐标梯度噪声、固定波长及 domain warp；保留可重复的既有构造，不把它改称侵蚀模型。短波截止改为 `wavelength >= 2 * cell_size`。地形高程单位为 m，坡度为 `sqrt((dz/dx)^2+(dz/dy)^2)`，x/y 间距先从 km 换算为 m。粗糙度改为 3×3 窗口局部高差除以两格距离，为无量纲局部起伏指标；曲率保留离散 Laplacian，单位 m⁻¹。支持单行/单列导数，并拒绝非正格距。

**限制。** Perlin 噪声只证明可生成平滑随机场，不证明地形具有真实地质统计。山脊、侵蚀门控、起伏振幅仍为场景参数，未模拟构造抬升、侵蚀、岩性或海岸。一个高原窗口不必出现全世界的最低海拔，也不必覆盖全世界全部 relief；只有 legacy 的逐图归一化才能保证每幅图触达两端。网格尺度的起伏不是风机微观空气动力粗糙长度 z₀。

## 2. 水文拓扑、湖泊、河宽和洪水易感性

**文献。** [Barnes, Lehman & Mulla (2014), Priority-Flood](https://doi.org/10.1016/j.cageo.2013.04.024)，及[作者参考实现](https://github.com/r-barnes/Barnes2013-Depressions)，支持边界向内优先队列填洼与数值平坦区处理。[Leopold & Maddock (1953), USGS Professional Paper 252](https://pubs.usgs.gov/publication/pp252)描述河宽、深度等水力几何量与流量的幂律关系。[Nobre et al. (2011), HAND](https://doi.org/10.1016/j.jhydrol.2011.03.051)用沿排水路径的相对高程刻画水文相关地形。

**原问题。** legacy 把局部汇流量分位数直接当河道门槛，改变地图范围就会改变河网。已有 conditioned 路径把 epsilon 造成的数值抬升计入湖深；转回 float32 后又可能丢失微小下降坡度。河流用“若干格”膨胀，30 m 宽的溪流可能被画成数 km 宽。`hydrology_elevation[water] = -depth` 把山间湖河直接移到海平面以下。所有湖泊统一挖 18 m，原洼地又被二次开挖。旧洪水打分中，低海拔和平坦本身会在没有河道的地方产生较大风险。

**处理。** 默认 `conditioned_v2`，默认不先平滑原 DEM：

1. 第一次 Priority-Flood 不加 epsilon，得到真实的溢流高程 `z_spill`。第二次仅以 float64 `nextafter` 的最小可表示增量解决平坦区流向，数值坡度不参与湖深。显式传入 `_priority_flood_fill(..., epsilon_m)` 的兼容辅助函数仍支持指定增量；v2 主路径不再使用旧 `depression_fill_epsilon_m` 作为物理参数。
2. D8 选最大下坡梯度；汇流量通过有向图入度队列累加，不再依赖高程排序的平局次序。每格贡献 1，`A = accumulation * cell_size_km²`；无环完整图上，各出口汇流量之和等于格子数。检测环并报错。河道门槛直接使用 `river_min_catchment_km2`，包含边界出口。
3. 湖泊先按整个连通洼地识别，按总面积 km² 和该洼地最大深度筛选；浅岸一并保留。水深为 `z_spill-z_original`，湖底保留原 DEM。`lake_min_area_km2` 替代 v2 中的最小像素数。
4. 河宽采用 `W_m = W_ref * (A/A_ref)^b`，再换算为栅格膨胀半径 `floor(W_m/(2*cell_size_m))`。默认参考宽度 30 m、参考面积 128 km²、指数 0.35 是可标定的场景假设，并非 USGS 给出的全球常数。河深采用 `clip(h_min*(A/A_min)^0.2, h_min, h_max)`，默认 0.5–12 m；同样只是几何近似。河床为当地高程减河深。
5. 默认洪水层改为 `exp(-distance_to_water / decay_km) * exp(-HAND / 5m)`。HAND 为沿 D8 流向遇到的第一个河湖单元的垂直高差；不汇入已识别河湖的路径风险为 0，水体自身为 1。5 m 尺度是未标定假设。此层是相对易感性，**不是洪水发生概率，也不是某重现期淹没深度**。
6. 距水距离改用精确欧氏距离变换，保留 km 单位，避免逐水像元遍历全图。

**限制。** A 是地形汇水面积，不是 m³/s 的流量；用 A 代替流量隐含空间近似均匀的有效径流。尚无降雨—蒸散—入渗—径流平衡、土壤或地下水过程，不能判断河道常年有水、湖泊能否长期维持。填洼按开放边界处理，不能模拟内流盆地。湖面依地形溢流高度定义，无湖容演变。粗网格至少保留一格中心线，因此 binary 水体面积仍会高估未解析的窄河；不可把 `river.sum()*cell_area` 当成真实河面面积。D8 排水有八方向偏好，HAND 在粗 DEM 下也不能替代二维水动力模型。`river_max_dilation_cells` 仍是显示层上限；legacy 的分位数、dilation、统一 lake_depth 等字段仅保留兼容。

## 3. 气候先于土地与植被

**文献。** [Lieth (1973), Primary production: Terrestrial ecosystems](https://link.springer.com/article/10.1007/BF01536729)建立温度、降水约束的 Miami 潜在净初级生产力模型；另见[Lieth 的 FAO 说明](https://www.fao.org/4/k1100f/k1100f04.htm)。[FAO (1976), A framework for land evaluation](https://www.fao.org/4/X5310E/x5310e00.htm)将气候、地形、水文等作为土地用途适宜性输入。

**原问题。** 土地层先于气候生成，植被只由局部坡度、海拔、距水和噪声决定：即使气候极干或极冷，min-max 之后仍必定有“最茂盛”地点。保护比例为 0 时，分位数比较仍会选出最大值像元；水域过多也会改变目标保护比例。土地成本按整幅图归一化，绝对坡度阈值的意义被冲淡。

**处理。** 执行顺序改为 `地形 → 地形排水拓扑 → 气候基线 → 土地/植被 → 城市 → 用地 → 能源候选`。保留排水拓扑在气候前，以便气候基线使用距水层。植被潜力采用

`V = min(1/(1+exp(1.315-0.119*T)), 1-exp(-0.000664*P))`，

其中 T 为年均 °C，P 为 mm/year；相当于 Miami NPP 除以 3000 g 干物质/m²/year，随后施加有限的地形及随机乘数，限制到 [0,1]。V 是**潜在植被生产力指标**，不是 NDVI 或实测覆盖率。没有 climate 的旧 API 调用保留参考气候 T=15°C、P=850 mm/year；主生成流程传入实际气候。坡度/局部起伏用固定尺度归一化，成本直接限幅。保护区按非水体总格数选定精确数量，比例 0 为空集；在土地面积一致时不会因河湖像元参与分位数而稀释比例。

**限制。** Miami 是气候潜力经验模型，不包含土壤肥力、作物品种、人类管理、CO₂施肥及高温/极端湿润损伤。保护区位置及成本权重依然是人为情景，不等价于任何地区法定范围。径流没有反向接受降水，所以当前顺序是一轮静态近似，不是完全耦合陆面系统。

## 4. 城市人口与空间守恒

**文献。** [Gabaix (1999), Zipf's Law for Cities](https://doi.org/10.1162/003355399556133)讨论城市规模的 rank-size 规律；[Tobler (1979), Smooth Pycnophylactic Interpolation](https://people.geog.ucsb.edu/~kclarke/Geography232/Pycno.pdf)强调空间插值的非负性和总量保持。

**原问题。** 城市规模权重写成倒序编号的正幂，和 rank-size 幂律不一致。多个城市的未经归一化核先叠加，会让核宽更大的城市获得更多人口；全图修正后再执行 min-max，将总人数完全抹去。选点不足时会把最小城市间距放松至 72%。配置 city_count=0 仍可能创建一个城市。

**处理。** 大小权重为 `w_r ∝ r^(-alpha)`，保留小幅情景扰动，按指定总人口分配到城市。每座城市先在可建设非水非保护区域计算空间核 K，再独立分配

`density_i = sum_c(P_c * K_ci / sum_j(K_cj)) / cell_area_km2`。

输出 `population_density` 单位改为 **persons/km²**，因此 `sum(density)*cell_area = sum(city.population)`。经济活动、城市形态仍使用 [0,1] 指标；它们不会改写人口总量。选点后备路径不再放松最小间距，城市数为 0 时返回空集，可建设性为 0 的像元不能作为中心。均匀且正值的气候/适宜性不再被清零。

**限制。** 使用了总量保持原则，但没有实现 Tobler 的完整 PDE 插值法。城市核、半径、气候舒适偏好、人口面积弹性与 alpha 均为场景参数，不能从真实地理推出人口因果规律。边界上的核截断后人口分配在当前区域内守恒，表示该区域承担给定城市的全部人口；不是跨区域人口流动模型。约束太严格时允许返回少于目标数量的城市。

## 5. 土地用途

**依据。** [FAO 土地适宜性评估步骤](https://www.fao.org/4/t0715e/t0715e06.htm)要求根据每类用途的水分、侵蚀、土壤等需求评价，而不是对所有用途使用同一绝对排名。

**处理。** 保留已有农业坡度 soft/hard 平滑限制、水域/保护区排除和不同用途的打分。农业平坦度改用固定物理坡度尺度；城市边缘指标先把 persons/km² 转成局部形态指标，再与 urban_density 比较，避免直接把物理密度减去无量纲数。统一正值场不再被归一化为 0。`residential/commercial/industrial/agriculture/park_green` 是相互可重叠的适宜性层，`land_use_zone` 是取最大值的互斥展示分类，`load_density_base` 是无量纲空间权重。

**限制。** 这些权重没有论文标定或真实土地调查支撑；保持为可解释的 demo 情景假设。它们不是面积占比（不要求和为1）、作物产量、真实地价或电耗。FAO 支持用途相关的评估框架，不支持代码中的具体权重。要作区域预测，必须补充土壤、道路、建筑面积、产业及真实土地覆盖数据。

## 6. 风光选址、面积约束及负荷规模

**文献。** [NREL ATB (2019), Land-Based Wind](https://atb-archive.nrel.gov/electricity/2019/index.html?m=1&s=ovcxcfpr&t=lw)使用 3 MW/km² 的装机面积密度估算技术潜力。[Denholm et al. (2009), Wind Land Use](https://doi.org/10.2172/964608)区分项目总面积和实际扰动面积。[Ong et al. (2013), Solar Land Use](https://research-hub.nlr.gov/en/publications/land-use-requirements-for-solar-power-plants-in-the-united-states/)统计公用事业级地面光伏占地，提供项目面积与容量/发电量的联系。

**原问题。** 将年均风速/辐照度按每图 min-max，均匀优良资源被清零，而低资源地图中最好的一格仍被提升为 1。GHI 已受云影响，PV 打分又扣除一次云。城市退距为软斜坡，后续松弛还会违反跨技术间距。聚类装机容量按邻域像素数放大，细化网格就能增加容量，重叠场站也重复使用土地。每个负荷节点用局部得分单独生成 MW，改变节点数量便会改变全网总需求，与人口脱钩。没有合适负荷位置时回退逻辑可能输出禁止位置。

**处理。** 风资源排序指数为 `clip(v/12,0,1)^3`；光资源为 `clip(GHI/250,0,1)`，分别保留绝对资源量级，不宣称是容量因子；PV 不重复扣云。城市退距、同技术间距、跨技术间距均为硬约束；无可行位置允许少选，不伪造满足目标数量的节点。

风光容量采用 `P_installed = min(usable_area_km2 * density_MW_km2, design_cap)`。场站使用固定 km 半径，以每格 4×4 子格面积求积，在各候选场站间分配到最近场站，跨风光技术也不重复使用同一子格；水域、保护区和城市核心不计可用面积。可建设性作为土地可利用比例近似。默认风电 3 MW/km²；PV 35 MW/km² 是与 NREL 报告的公用事业级占地量级相近的可调假设，不是跨国家/年代通用常数。原 capacity_min/max 仍用于候选中间状态兼容，最终容量受土地与 `capacity_max * cluster_max_multiplier` 设计上限限制，土地不足时不会抬高到虚假的最小装机。

负荷总峰值为 `P_peak_MW = population * per_capita_peak_load_kw / 1000`。默认 1.5 kW/person 是**未标定的情景尺度**，包含区域居民及非居民部门的汇总峰值，并非某研究发现的固定人均值。各负荷节点按不重叠的最近服务区分摊，人口乘以土地用途权重仅重新分配空间形状；全网峰值不随候选节点数量改变。最终负荷节点容量不受旧每点最小/最大范围约束，否则会破坏总需求守恒。

**限制。** 没有风机尾流、坡面辐射、详细场站工程、道路、经济约束和输电可达性优化；4×4 求积具有离散误差，不是地籍级用地分割。假设風光项目用地互斥，不含农光互补/风光共址。装机密度是 MW/km²，不能误读为年平均发电功率密度。年均风速的立方不等于逐时风功率期望，真正的机组出力留给天气驱动的源荷阶段。

## 验证

新增 `tests/test_geography_physics.py` 覆盖 14 个参数化测试实例：平坦高程的排水和总汇水面积、图拓扑顺序及环检测、湖面/湖底/浅岸和地形基准、HAND 基准不变性、物理河宽、坡度/粗糙度的尺度、气候对植被的限制、保护比例0、不同格距和多城市人口守恒、城市间距、跨技术场站不重复占地、分辨率与面积装机、人口总峰值及负荷点数量独立性、选址退距、均匀正资源。

运行方式：`D:\anaconda\python.exe -B -m pytest -p no:cacheprovider tests/test_geography_physics.py -q`。不安装包，不修改 conda 环境。测试验证数学约束和代码行为；不构成与真实流域、城市或电网的统计校准。

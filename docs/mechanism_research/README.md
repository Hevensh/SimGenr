# SimGenr 多模态文献与机理调查

本组报告调查地理、气象、生态、能源与电力系统之间的关系，将其整理为有单位、时空尺度、适用边界和验收条件的合成规则。研究以 `d064633`（physics_v3 合并后的实现）为代码基线；资料核对日期为2026-09-09。

这是一份**研究与实施设计交付**：没有下载、清洗或拟合真实区域数据，没有评价神经网络，也没有在本次文档变更中启用所建议的新物理模块。每篇都区分当前实现、建议规则与未覆盖过程。上一轮实现的测试证据仍见[既有验证报告](../VALIDATION_RESULTS.md)，不能将其解释为本轮所有建议已通过测试。

每篇使用统一的11个章节，并在第12节给出“建议立即实现 / 建议后续实现 / 暂不实现”。因果图使用GitHub可渲染的Mermaid，变量影响表列明输入、输出、方向、空间尺度、时间尺度、关系类型、推荐实现与来源。

关系的三种分类：

- **物理关系：** 守恒、几何、量纲或基本过程约束；仍需注明所用近似的成立条件。
- **经验规律：** 实验/观测归纳或经验闭合；参数随设备、区域、时段和支撑尺度改变。
- **场景先验：** 世界类型、容量、权重、概率及初边值的人为设定，不是普适事实。

“工程简化”描述如何实现上述关系，不能取代其关系分类。文献中的数值示例、当前配置和建议扫描区间分别标记；参考资料的用途逐条说明，引用真实资料只为支持机理与结构。

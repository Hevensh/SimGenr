# B：气候扰动的物理空间尺度

本记录只涵盖气候背景噪声与地形转向中的风向噪声，属于 B 工作包。天气原始态和诊断量由 B 的天气子任务处理；此处没有提前实施土地、水文、源荷或地形改动。

## 改动与分类

**P：空间单位换算。** 气候调用共用的 `weather/random_fields.py::gaussian_field`。对于等距正方形网格，输入的潜在高斯场协方差衰减距离为 $L$ km，卷积标准差使用

$$\sigma_{\mathrm{cell}}=\frac{L}{2\Delta x},$$

其中 $\Delta x$ 为 `WorldGridConfig.cell_size_km`，单位 km/cell。在无限域、充分分辨的高斯卷积近似下，卷积核自相关为 $C(r)/C(0)=\exp[-r^2/L^2]$，所以 $L$ 是潜在场协方差降至 $e^{-1}$ 的距离。共用函数截断卷积核于约 $3\sigma$，离散网格和边界会改变精确协方差。这个换算是数学关系，不是新增大气过程定律。

**S：合成扰动与边界先验。** 潜在场 $Z$ 使用共用函数的单位边际方差归一化，再经固定标准正态分布函数 $N=\Phi(Z)$ 映射至 $[0,1]$。气候中的原有扰动使用 $N$，风向扰动继续为 $\delta\theta=\theta_{\max}(2N-1)$，单位度。这里 $\theta_{\max}$ 为已有 `wind_direction_noise_degrees`。每个实现不必恰好空间均值为零；$L$ 描述潜在高斯场，不能宣称有界场或最终地形转向后风场具有完全相同的高斯协方差。

**工程简化。** 固定 CDF 替代物理模式下的全图最小值/最大值拉伸，避免新增区域极值改变全图扰动幅度定义；保持原有气候温度、湿度、风速和降雨评分公式。噪声不会因网格数量直接改变目标 km 尺度。`reflect` 表示反射延拓的数值边界；`periodic` 显式表示周期合成域。两者均不表示真实区域侧边界气象条件。

**E：既有气候关系。** 温度递减率、地形迎背风代理和云辐照关系沿用原实现及研究报告的范围声明，本改动未新增、校准或强化这些经验结论。对应研究背景见 [任务04](mechanism_research/task_04_climate_and_orography.md) 的背景场、地形修正与局限性，和 [任务05](mechanism_research/task_05_cloud_rainfall_radiation.md) 的随机场降阶原则。

## 配置与兼容

| 配置项 | 默认值 | 单位与检查 | 含义与适用性 |
|---|---|---|---|
| `climate.spatial_scale_mode` | `physical` | `physical` / `legacy` | 显式选择公里尺度或旧像元算法 |
| `climate.climate_correlation_length_km` | 20 | km，有限且大于 0 | 气候共同背景扰动的潜在协方差距离；S，未校准默认 |
| `climate.wind_direction_correlation_length_km` | 12 | km，有限且大于 0 | 地形转向前风向扰动的潜在协方差距离；S，未校准默认 |
| `climate.spatial_boundary` | `reflect` | `reflect` / `periodic` | 合成域边界先验 |
| `climate.wind_direction_smoothing_steps` | 6 | 非负整数，不接受布尔值 | 仅 `legacy` 模式使用；保留历史像元平滑参数 |

默认 20 km 和 12 km 是本项目为了分离较宽背景扰动与较局地风向扰动选择的场景尺度，**不是文献拟合参数或全球通用气候常数**。配置不设置缺乏依据的经验上限；当 $L$ 小于网格间距时相关结构不可分辨，当 $L$ 接近或超过地图尺度时样本可能近似整体同向扰动，不能据此估计真实气候空间统计。

`ClimateConfig` 新字段位于旧字段之后，保留旧位置参数顺序；既有 `_validate_scale_config` 留给气候与天气共用。`small_debug.yaml` 明确写出新模式和公里参数。完整配置快照保留模式、长度、边界和旧参数，支持往返读取。

显式 `legacy` 模式保留旧 `_smooth_noise`、其全图归一化以及背景固定 5 次/风向配置次数的像元模板。物理模式完全绕过该模板，更改旧平滑次数不会改变物理模式的输出。旧配置文件仍可解析；如果文件没有新模式字段，将使用新的 `physical` 默认，**不会自动伪装为旧结果复现**。需要旧行为的调用者必须显式指定 `legacy`。新物理模式会改变既有种子的气候实现，由整个工作包的 `physics_v4` 语义版本管理。

## 验证与边界

实际测试使用 Git Bash 启动 `/d/anaconda/python.exe -B -m pytest`，缓存与临时文件均位于仓库 `outputs`。独立文件 **21 项通过**；加上现有气候相关回归筛选运行 **23 项通过、48 项未选中**。未选中不等于失败或通过，不据此宣称全部 B 工作包验收完成。

核心测试不是比较两个随机地图是否逐像元相等，而是向实际气候噪声路径输入确定性脉冲、逆 CDF 还原潜在场，测量其响应宽度。$L=8$ km，分别使用 129×129 / 1 km、257×257 / 0.5 km、257×257 / 1 km、513×513 / 0.5 km，得到相同物理距离处的归一化核响应；标准差在截断误差允许的 2% 内等于 4 km。这同时覆盖同域加密与扩大地图两种比较。

其他检查确认：真实生成入口将两项不同的 km 长度和实际网格间距传至共用函数；物理模式不调用旧像元模板；风向单位向量范数和角度边界满足原约束；显式旧模式与旧模板数值完全一致；两个模式的快照均可往返；零、负、NaN、无穷长度及非法模式拒绝；单行、单列和单格输入保持有限。

同种子在不同形状下并不保证重叠区域为同一个随机实现，当前随机数仍按数组形状抽样；本次保证配置对应的物理响应尺度，而不是世界坐标拼接连续性。反射边界附近的相关结构与内域不同，较大的相关长度尤其明显。未来若需要区域拼接，应另行实现世界坐标随机场及 halo 生成，不能把本次尺度验证当成已经完成该功能。
